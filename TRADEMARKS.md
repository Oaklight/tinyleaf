# Tinyleaf trademark and naming policy

Tinyleaf names, logos, icons, and other brand assets identify the Tinyleaf project and its maintainers.

The software code is licensed under AGPL-3.0-or-later starting with Tinyleaf 0.5.0. The Tinyleaf name and logo assets are project branding and are not a general trademark license for confusing commercial use.

## Allowed uses

You may use the Tinyleaf name and logos to truthfully refer to the project, including:

- saying that your project integrates with Tinyleaf
- writing tutorials, reviews, or documentation about Tinyleaf
- showing Tinyleaf screenshots or package metadata
- linking to the official Tinyleaf repository or documentation

## Uses that need permission

Please ask for permission before using Tinyleaf branding for:

- a hosted service using a name such as "Tinyleaf Cloud", "Tinyleaf Hosted", or similar
- a domain, product, company, or app name that could be confused with the official Tinyleaf project
- modified logos or marks that remain confusingly similar to the official Tinyleaf marks
- merchandise, paid services, or marketing that implies endorsement by Tinyleaf/Oaklight

## Forks and modified versions

You may fork and modify the software under its code license. If you distribute or host a modified version, use a distinct name and branding unless you have permission to use Tinyleaf branding.

Clear attribution is welcome, for example:

> Based on Tinyleaf, an AGPL-licensed LaTeX web editor.

Avoid wording or branding that suggests your fork or service is the official Tinyleaf project.

## Contact

For brand or trademark permission, open an issue in the official repository or contact the maintainers listed in the project metadata.
